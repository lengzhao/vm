# 技能行为验收场景

用这些场景检查技能是否让后续开发作出正确决定；实际实现仍需运行对应 Go 测试。

1. **替换编译器和审查器**：第三方实现分别只有 Compile(ctx, source) 和 Review(source)。应能注入；不能为了兼容旧调用而给 core 增加 Validate/InjectGas/白名单查询。
2. **新 Gas 算法与旧画像**：内建估算器收到版本 0 或其他未知版本应拒绝；根包旧 helper 可以复制并把历史版本 0 归一化。不能让不同模型版本静默共享算法。
3. **自定义确定性策略**：ID 为 my-policy-v2，声明确定性保证。Compiler/ArtifactValidator 不以具体 ID 名称识别确定性；产物保存保证，缺失保证或不被接受的策略仍拒绝。
4. **启动 A 成功、B 部分失败、C 未启动**：回滚顺序是 B、A；不 Stop C；清理使用独立 context。
5. **关闭超时后重试**：已成功关闭项不重停；当前失败项及其依赖保留，新 context 重试继续逆序关闭。普通错误和瞬时 context 错误的缓存语义不同。
6. **同地址 Put 第二份产物**：读到新代码，新画像为空时旧画像消失，输入编译产物不变。失败不应静默丢弃旧记录；多实例事务不在当前保证内。
7. **只使用 ABI 插件**：依赖链不应引入编译/进程/引擎整包；生产插件不依赖历史测试目录 internal/builtin。
8. **验证与提交**：普通测试、race、vet 依次验证，分别记录结果；显式核对暂存范围，不提交 .codegraph、contracts、test_contracts 等本地生成目录，不自动推送。
