# Gas 模型推进 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 统一合约侧 Gas 到 `contractapi`（含默认库扣费），Compile/Deploy 产出 `GasProfile`，并实现 `EstimateGas`（静态保守上界 + 可选 DryRun）。

**Architecture:** 执行扣费全部走 `contractapi.ConsumeGas`；编译期 AST 扫描写入 `gas_profile.json`；`VMEngine.EstimateGas` 默认读 Profile 估算，`DryRun` 则复用 `ExecuteWithContext` 取实际消耗。设计见 `docs/plans/2026-07-21-gas-model-design.md`。

**Tech Stack:** Go 1.22+、`go/ast`、现有 `ProcessRunner` / `contractapi` embed 管线

**参考设计:** @docs/plans/2026-07-21-gas-model-design.md

```go
const (
	GasEntryBase     = 10
	GasFuncOrLoop    = 1
	GasBlockHeight   = 1
	GasBlockTime     = 1
	GasSender        = 1
	GasContractAddr  = 1
	GasLog           = 2

func InitGas(limit uint64)
```

各 API 入口调用对应 `ConsumeGas`。`Reset()` 事件缓冲时不强制清 Gas（由 entry `ResetGas`/`InitGas` 负责）；可在 `InitGas` 内清零 used。

**Step 3: 最小实现**

```go
type FunctionGasProfile struct {
	FuncEntries int            `json:"func_entries"`
	LoopSites   int            `json:"loop_sites"`
	APICalls    map[string]int `json:"api_calls"`
}
type GasProfile struct {
	Version  int                           `json:"version"`
	EntryGas uint64                        `json:"entry_gas"`
	Functions map[string]FunctionGasProfile `json:"functions"`
}
func BuildGasProfile(source string) (*GasProfile, error)
func EstimateFromProfile(p *GasProfile, function string, loopBound uint64) (uint64, map[string]uint64, error)
```

扫描规则见设计文档第 6 节。`EstimateFromProfile`：`loopBound==0` → 1000。
