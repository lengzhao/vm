# D2 可插拔 WASI 后端与比较计划

**Goal:** 新增独立可配置的 WASI 编译器和 wazero Runner，实测比较并给出适用场景。

**Architecture:** 用户确认所有后端均是插件选择。注册 compiler/wasip1、runner/wazero，复用 Go AST/ABI/Gas/清单流水线及调用协议，产物显式区分 wasip1/wasm。保留 compiler/go、runner/process、runner/docker 与默认配置。编译插件可组合 Docker 编译隔离。core 能力契约不扩大。

**Tech Stack:** 标准 Go WASI、固定版本 wazero、PluginKit、现有协议 3。

## 已确认设计

- 编译器目标是插件选择，不由 Engine 硬编码。缓存/清单覆盖目标、实际工具链和可选镜像，互不误命中。
- 提取共享协议会话；执行传输可为进程或进程内 WASI。初始请求和回复有独立有界输入，禁止 WASI stdout 回调写阻塞管道导致死锁。
- Runner 默认不挂载文件、不提供网络、不继承宿主环境；限制 Wasm 线性内存、模块字节和执行时间。WithCloseOnContextDone 终止非合作死循环。宿主函数也必须遵守 context，VM 总 RSS 不等于 guest 线性内存限制。
- 本批采用每次调用独立 runtime（无常驻编译缓存），保证并发隔离、嵌套重入生命周期简单并能完整关闭；测量需包含此成本。不将源码 Gas 伪称任意 Wasm 指令 fuel。
- 验证 ABI 数值/事件/Gas、Object、跨合约事务及失败/OOG/DryRun/取消回滚；恶意文件/网络/输出/内存/死循环与错误目标拒绝。
- 基准比较同一源码和输入的 Process（开发基线）、Docker（D1 隔离）及 wazero；分别报告真实编译和调用耗时、产物体积/Go 分配，不将进程内 alloc 等同跨进程 RSS。基于本机证据推荐配置，不删除其它插件、不自动切换默认。

## 执行与验证

1. 先加 compiler/wasip1 插件装配与产物目标失败测试，运行后实现可选目标，保留原 Go 工具链探测约束。
2. 提取共享协议会话，先覆盖同步 WASI Host 回复不死锁、错误响应及取消；回归 Process/Docker。
3. 先加 wazero 插件配置、隔离和集成测试，再实现固定内存、context 终止、最小 WASI 权限、模块快照摘要校验。
4. 补全配置、文档及可重跑基准，实际记录数据，给出后端选择边界。
5. 依次运行全量普通、race、vet、diff 检查（Docker 用例显式启用），独立审查并修复；变更留当前 dev 工作区，不提交。

## 验证中的修正

- 取消分类复核发现 WASI 产物校验路径可能返回裸 context 错误；现通过 validateArtifact 保留 CANCELED/TIMEOUT，增加先失败再实现的回归。
- race 对模块 JIT 的插桩开销远高于普通执行。最初把 net/os/fmt 负例链接进每个事务帧，跨合约场景触发原 20 秒父预算；拆分事务与权限/资源夹具后，事务及跨合约 race 通过。进一步将网络权限与内存/输出拆成独立最小合约，避免资源测试编译无关网络代码。最初保留 20 秒 Runner / 30 秒 Engine；最终全量 race 及单独复现仍在 Child 处取消（测试总时长分别 111.20 / 106.59 秒），说明最小双模块 JIT 在 race 下仍不能稳定满足父预算。调整后定向 race 通过，单帧 Add / Width 为 14.40 / 12.89 秒，Child 为 19.67 秒，已接近原 20 秒上限。现仅语义集成测试使用 60 秒 Runner / 90 秒 Engine，并记录调用耗时；生产默认和专用短取消/无插桩死循环测试预算及生产超时逻辑均未修改。
- 严格资源错误断言发现初始 Flood 仅 672×1500=1,008,000 字节，低于 1 MiB，先前实际因协议错误失败。现为 672×2000=1,344,000 字节，必须返回 OUTPUT_LIMIT；内存负例必须为包含 memory 诊断的 PROCESS_FAILURE，不能用超时充数。定向资源 race 已通过。
- 独立审查和最终测试拆分复核未发现剩余明确 P1/P2。最终全量验收结果以 todo.md 记录为准。
