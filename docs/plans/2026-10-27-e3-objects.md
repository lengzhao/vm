# E3 Objects Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 提供可选多对象和宿主强制的 owner 授权，复用现有事务。

**Architecture:** core 定义对象命令、绑定服务与独立授权能力；internal/objects 实现单记录事务存储；plugins/objects 注册工厂，engine/objects 显式注入。contractapi 和共用 execution 协议连接 Process/Docker/WASI。

**Tech Stack:** Go、PluginKit、现有 StateTransaction/MVCC/bbolt；无新依赖。

### 1. 对象存储与权限
- 新建 core/objects.go、internal/objects/objects.go、internal/objects/objects_test.go。
- 先写创建/读写/越权/转移/删除墓碑/隔离与冲突测试，运行 go test ./internal/objects 确认失败。
- 实现 ObjectService.Bind / ObjectSession.Apply / Err 与 ObjectAuthorizer.Authorize，owner 规则独立实现；所有错误锁存，整个操作串行，输入输出复制。
- 补取消、资源上限和元数据损坏测试，验证通过。

### 2. 合约协议与装配
- 修改 contractapi/object.go、internal/execution/object.go、internal/engine/call.go、internal/engine/engine.go、internal/security/security.go。
- 新建 plugins/objects/register.go、plugins/engine/objects.go；修改 plugins/all/all.go。
- 先写 contractapi wire、宿主最低 Gas/禁用插件失败测试及 assembly/objects_test.go 真实合约测试，运行定向测试确认失败。
- 新对象请求只由宿主绑定 scope；create/owner/transfer/destroy 有独立 Gas；默认 Object 兼容。帧结束关闭服务，不能用保存的引用继续操作。
- engine/objects 消费原组件与 ObjectService，返回具体 Engine，保留 TransactionExecutor/DryRun。新增 presets/objects.yaml。

### 3. 集成、文档与验证
- 覆盖真实执行、越权、忽略错误、父失败、DryRun、跨合约主体、并行冲突、持久重启和恢复回执。
- 新建 docs/objects.md，同步 docs/plugins.md、README.md、todo.md。
- 顺序运行 go test -p 1 -timeout 5m ./...、go test -race -p 1 -timeout 5m ./...、go vet ./...、git diff --check；使用现有匹配工具链与临时缓存。
- 按用户要求再提交；本次开发不自动提交或推送。
